  <action>
    **CliOpts change:** Replace `serialPath: string` with `serialPaths: Array<{ path: string; position: string | null }>`. Keep backward compat: if `--serial-path <path>` is used, map to `[{ path, position: null }]`.

    **New --serial flag:** `--serial <path>[:<position>]` — repeatable. Parse colon as separator only when the segment after the last colon is a known position label ('left', 'right') or a user-defined string. Examples:
    - `--serial /dev/ttyUSB0:left --serial /dev/ttyUSB1:right`
    - `--serial /dev/ttyUSB0` (position = null)
    - `--serial-path /dev/ttyUSB0` (backward compat, position = null)

    **Help text update:** Add --serial documentation, mark --serial-path as deprecated alias.

    **BridgeLifecycle constructor:** Add `position: string | null` as fifth parameter. Store as readonly field. Pass to attachBridge so the bridge can include position in WS envelopes.

    **Lifecycle array:** Replace `let lifecycle: BridgeLifecycle | null = null` with `const lifecycles: BridgeLifecycle[] = []`. Loop over opts.serialPaths to create one per entry. Set app.reconnectBridge to reconnect the first lifecycle (backward compat for the health endpoint).

    **Shutdown:** Replace single lifecycle.stop() with for-of loop over lifecycles.

    **WS broadcast extension:** When BridgeLifecycle emits a card_read event, include `reader_position: this.position` in the WS envelope payload. The existing card_read shape gains an optional `reader_position: string | null` field.
  </action>
