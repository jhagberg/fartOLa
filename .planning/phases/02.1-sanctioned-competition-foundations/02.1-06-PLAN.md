  <action>
    Create packages/sportident/src/SiStation/readBackup.ts:

    - Source: pcprog5-v11-2018-10-15/pcprog5.pdf section 3 and BSx7_8_readbackup.txt. Re-authored against the spec, not ported.
    - Export BackupRecord interface: { cardNumber: number, punchTime: { secondsInHalfDay: number, halfDay: number } | null }
    - Export parseBackupBlock(block: Uint8Array, recLen: number): BackupRecord[] — parse 128-byte block into records at recLen stride. Card number at bytes 0-3 (big-endian uint32) within each record. Skip records where card number is 0 (empty slot).
    - Export parseMemPointer(sysVal: Uint8Array): number — extract the current memory write pointer from GET_SYS_VAL response
    - Export parseOverflowFlag(sysVal: Uint8Array): boolean — extract overflow bit
    - Export readBackupMemory(station: SiMainStation): Promise<{ records: BackupRecord[], overflow: boolean }> — orchestrates GET_SYS_VAL + GET_BACKUP loop. Hard cap: MAX_ITERATIONS = 512 (BSF8 has max 32KB memory / 128-byte blocks = 256 blocks; cap at 2x for safety). If loop exceeds cap, return partial results with overflow=true.
    - Add exports to packages/sportident/src/index.ts

    Use the existing proto.cmd.GET_BACKUP (0x81) and proto.cmd.GET_SYS_VAL (0x83) constants.

    BLOCK_SIZE = 128 bytes. Default REC_LEN = 8 bytes for extended protocol check-unit mode.

    Addresses review concern (Gemini HIGH — stale punch ghosts): The route accepts an optional eventWindowHours parameter (default 12). Backup records whose punch timestamps fall outside the event window (older than eventWindowHours before the competition start time) are filtered out before returning. This prevents "ghost" runners from a previous training event appearing as missing. When the check station memory has overflowed, the overflow flag is set and the UI warns that the list may be incomplete.
