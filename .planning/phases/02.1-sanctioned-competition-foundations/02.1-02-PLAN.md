    Create apps/edge/src/draw/soft.ts implementing the SOFT algorithm re-authored from the algorithm described in oEventDraw.cpp:130-209 (NOT ported — re-authored against the algorithm):
    1. Group runners by club
    2. Largest club becomes group 0
    3. Distribute remaining clubs into N bins where N equals the size of the largest club (per D-04)
    4. **Use iterative binning (NOT recursion).** The original MeOS algorithm uses recursion on sub-groups, but this risks stack overflow on large classes. Instead, use an iterative approach: repeatedly bin the remaining runners by club size, interleaving bins at each level, until all runners are placed. If a recursive approach is used despite this guidance, enforce a MAX_RECURSION_DEPTH of 20 and fall back to Fisher-Yates shuffle if the depth is exceeded. (Addresses DeepSeek HIGH: SOFT recursion depth.)
    5. Shuffle group order, interleave by level
    Use crypto.randomInt for shuffling (not Math.random).

    Addresses review concern (GPT MEDIUM — flaky randomized tests): Accept an optional rngFn: (min: number, max: number) => number parameter on all draw functions. Default to crypto.randomInt. Tests inject a seeded deterministic RNG for reproducibility.

    Addresses review concern (GPT HIGH — SOFT impossibility): When a single club has more than ceil(N/2) runners, perfect zero-adjacency is impossible. The algorithm must handle this gracefully: place same-club runners as far apart as possible, report the adjacency count in the return value { order: DrawResult, adjacencyCount: number }, and never crash or loop forever.

    Create apps/edge/src/draw/random.ts — Fisher-Yates with crypto.randomInt.
