# 02.1-15: one start choice per class (ADR-0018)

> **For agentic workers:** REQUIRED SUB-SKILL: use
> superpowers:subagent-driven-development (or executing-plans) to run this
> plan task by task. Steps use checkboxes.

**Goal:** the operator says once how a class starts, with three answers, and
Lottning, Kontroll and the results all read that answer.

**Decision:** `docs/decisions/0018-one-start-choice-per-class.md`. Read it
first; it has the table every task implements.

**Rules:** ADR-0011 (SOFT TR 4.18.16, 7.4.2, 7.4.3), ADR-0016 (rule 7
floors: 14 px, 44 px, never colour alone; plain Swedish), ADR-0014 (replay),
ADR-0003 (migrations hand-written, strictly increasing `when`).

**Tech:** Fastify edge with Drizzle/SQLite and the event-sourced projection;
Svelte 5 web; node:test (edge), vitest (web), Playwright.

## Global constraints

- One column, one new value: `classes.start_method` gains `free_start`.
  No new column, no new table.
- Stored `auto` keeps its meaning (the runner's start time, else the start
  punch). Nothing in this plan rewrites an `auto` row.
- `free_start` times exactly like `start_punch` (punch, else drawn time).
- No change to what a result is for any class that keeps its stored value.
- Never raw server text or codes in the UI; new keys in `sv.json` and
  `en.json`.
- Gate per task: `rtk proxy pnpm lint && pnpm typecheck && rtk proxy pnpm test`.
  e2e behind `flock /tmp/fartola-e2e.lock pnpm exec playwright test <specs> --workers=2`.
- Each new test is shown RED first, with the reason it fails on the old
  code.
- Commits: Conventional Commits, one per task, no trailers.

## The table (from the ADR)

| Answer (sv)                        | Stored        | `startSource`          | `classNeedsStartTimes`   |
| ---------------------------------- | ------------- | ---------------------- | ------------------------ |
| Lottad starttid                    | `start_time`  | drawn                  | true                     |
| Lottad starttid och startstämpling | `start_punch` | punch, else drawn      | true (was false)         |
| Fri start med startstämpling       | `free_start`  | punch, else drawn      | false                    |
| not chosen (older competitions)    | `auto`        | drawn, else punch      | unchanged legacy rule    |

`freeStartForbidden` (a confirmed age class at nivå 1–3) still forces
`classNeedsStartTimes` to true, whatever is stored.

- [ ] **Step 4 (RED), the defaults:** a helper in `draw/classKind.ts`:

  ```ts
  /** The start choice a new class gets (ADR-0018): free start for open
   * classes and inskolning, a drawn start time for an age class, and
   * drawn with start punch when the kind is unknown, so nobody is left
   * without a time and Kontroll asks. */
  export function defaultStartMethod(kind: ClassKind | null): StartMethod {
  ```
