    - Export refreshClassCache(meosHost: string, fetchImpl?: typeof fetch): Promise<Map<string, number>>
    - GET http://<meosHost>:2009/?get=class with 5s timeout
    - Parse response with fast-xml-parser (same config as mop.ts: ignoreAttributes: false, attributeNamePrefix: '@_')
    - Extract cls elements: @_id (number) and #text (class name string)
    - Build Map<string, number> from the entries

    - Add @_classid: classId to the entry element attributes alongside the existing @_classname
