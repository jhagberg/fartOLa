## Why

ADR-0006 version policy: run the newest Node.js LTS line. Node 26
enters Active LTS on 2026-10-28 and is supported to 2029-04-30; Node 24
goes to Maintenance on 2026-10-20 (EOL 2028-04-30). `engines` on the
edge already allows `^24.15.0 || >=26.0.0` (PR #52).

## What

After 2026-10-28, on a branch:

- `.nvmrc` → 26; CI runs on it. Root `engines` → `>=26` once the
  edge range is no longer needed for 24 (or keep 24 allowed for one
  release, then drop it).
- Rebuild native modules (`better-sqlite3`, `serialport`, `sharp`) and
  check prebuilt binaries exist for 26 on linux-x64 and linux-arm64.
- Gate (`pnpm lint && pnpm typecheck && pnpm test`), e2e, and both
  real-competition replays (DM dag 1 633/634, Tuna Ting dag 2 608/609).
- Bench: one readout and one receipt with a real BSM8 and printer.
- Note: Node 27 starts the yearly model (alpha from 2026-10, release
  2027-04, LTS 2027-10); the next move is 2027-10.

## Done when

All of the above pass on 26 and the PR is merged.
