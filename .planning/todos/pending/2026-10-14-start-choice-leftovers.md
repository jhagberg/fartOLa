Left out of ADR-0018 on purpose (design-lab, 2026-10-13), written down
so they are not lost.

1. **Booked free interval start** as a fourth start answer: the runner
   books a start time inside a window instead of being drawn. The rule
   matrix has no row with data for it yet; find the rule text first and
   add the row before designing anything.
2. **A start column in the class table on Tävlingsinfo** (option E in
   the ADR): shows each class's start choice where the classes are
   listed. Small, but it is a second place to change the choice, so
   decide whether it only shows it or also edits it.
