## Problem

The draw plan bans pursuit (jaktstart) in inskolning and D/H10–12 (TR
7.4.1 names only "jaktstart"). We also ban reverse pursuit (omvänd
jaktstart) there, to be careful, because the text is unclear:

- TR 7.4.1 lists interval, free interval, mass start, pursuit and reverse
  pursuit as allowed in all competition forms, and bans only "jaktstart"
  in inskolning and D/H10–12.
- TR 7.4.2 lists the start orders allowed in åldersklass: lottning, fri
  intervallstart, gemensam start, jaktstart. Reverse pursuit is not on
  that list at all.
- TR 7.4.3: open classes (inskolning is one) use free start time.

So: is reverse pursuit allowed in åldersklass at all? In D/H10–12? Is the
ban on pursuit in inskolning moot because open classes must have free
start time?

## What

- Ask SOFT (or a tävlingskontrollant) how TR 7.4.1–7.4.3 are meant to be
  read for reverse pursuit; record the answer and its source.
- Install SOFT's program OLA (the owner will download it) and check what
  it allows: which start methods per class type, how it draws (club
  separation, vacancies, late entrants), and how it handles pursuit.
  Use OLA as a second reference next to MeOS for the draw tests.
- Update the TR 7.4.1 row in the rule matrix and the draw route's ban to
  match, with a test named after the rule.

## Done when

The rule reading is confirmed from SOFT or a TK, and fartOLa's ban and
the matrix row match it.
