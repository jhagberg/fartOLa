# Design-lab audit, per screen

Input for plan 2 (per-screen passes). One section per screen, 16 in all.
Each table lists what plan 1 (the building blocks) does **not** solve. The
"Solved by plan 1" line names what the building blocks already fix, so it
is not repeated as rows.

- **Checked against:** ADR-0016 (rules 1-7), the ui-ux-pro-max quick
  reference (sections 1 accessibility, 2 touch and interaction, 5 layout,
  6 typography and colour, 8 forms and feedback, 9 navigation), the taste
  rules in the spec ("Inputs"), and the 2026-10-09 audit (`REPORT.md`,
  cited as "audit R3" and so on).
- **Evidence:** the "before" screenshots (16 screens, laptop 1366x768 and
  tablet 820x1180, default and bright-sun, plus the four colour-blind
  readout shots) and the `.svelte` source. Line numbers are in the
  worktree at the start of plan 1 (before Tasks 3-10 change the files);
  find selectors by name if a number has moved.
- **Sev:** high = the volunteer believes something false, loses work or is
  blocked from the main task; medium = slower or confused but recoverable;
  low = polish. Same scale as the 2026-10-09 report.
- **[behaviour] rows** change behaviour or data flow, outside the spec's visual + wording scope; plan 2 decides per row.
- **Test-environment noise, not findings:** the consent toast over the
  readout, "Frånkopplad" (no reader in the test run), the duplicate
  "Warm-up" competitions on the home screen.
- **Shared fixes, do once:**
  - **`--fs-caption`:** 12 px today (LO-8, used in about 17 places); set it to 14 px.
  - **Undefined tokens:** `--err`, `--warn`, `--bg-hover` and `--bg-soft` do not exist in `tokens.css` (EX-1, KV-5, EV-1, RO-19, WA-8). Replace by `--dnf` / `--dnf-soft` for errors, `--mp` / `--mp-soft` with `--mp-fg` text for warnings, `--bg-sunken` for hover and soft fills; never define new aliases.
  - **`--scrim`:** one token for the four copies of `rgba(20, 20, 30, 0.32)` (RO-17).
  - **`--mp-fg`:** one token for amber text (WA-10).
  - **Disabled primaries:** stay disabled and show a hint saying what is missing (RG-3).
  - **Focus ring:** delete the component-level `:focus` outlines so the global ring applies (IN-7).
  - **Frame components** (sidebar, top bar, station card, race-phase control, competition switcher) are on every screen and are audited under Avläsning.
